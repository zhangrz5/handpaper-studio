# 绘报工坊

按年级和风格生成手抄报的本地网站，电脑和手机使用同一个网站。真实图片生成通过本机 Codex App Server 的内置图片生成工具，使用 ChatGPT / Codex 订阅登录，不读取或转发账号凭据，不调用收费 Images API。

## 启动

需要 Node.js 20 以上版本和较新的 Codex 客户端。网站优先使用已安装的 Codex 桌面版自带客户端，再寻找全局 CLI；GPT‑6.1 Sol high 已通过桌面版自带的 0.160.0 实际调用验证。无需安装网站依赖。

双击 **启动网站.cmd**，或在此目录运行：

```powershell
node server.mjs
```

默认地址为 `http://127.0.0.1:8787`。直接打开即可使用，无需网站口令。

若网站显示“连接本机订阅”，点击连接并在 OpenAI 官方页面完成设备授权；也可以在电脑终端运行 `codex login`，使用 ChatGPT 账号登录。账号需支持 Codex 内置图片生成。登录授权需要本人完成。网站只接受订阅登录，API key 登录不能发起生成。

## 手机与 frp

把 frp 映射到本机 **8787** 端口，手机直接打开你的 frp 域名。页面和图片接口使用同一个来源，无需在手机配置本地地址。电脑网站服务需保持运行。反向代理保留 Host。

frpc TOML 的 HTTP 代理示例，替换你的服务器地址和域名：

```toml
serverAddr = "你的frp服务器地址"
serverPort = 7000

[[proxies]]
name = "handpaper-studio"
type = "http"
localIP = "127.0.0.1"
localPort = 8787
customDomains = ["你的域名"]
```

域名的 HTTPS 终止由你的 frp / 反向代理配置完成。按你的要求，网站不设置访问口令，保留同源校验和请求令牌。只需映射本网站的8787端口，Codex App Server使用进程内部通信。

## 生成与描绘

- 年级：小学一年级至高三，细节预算随每个年级增长，低年级大形状平涂，初中丰富层次，高中增加纹样和细节。
- 风格：国潮大气、酷炫风、活泼卡通、清新自然、科技未来、动漫热血、黑金大气、梦幻星空。风格与年级分别约束视觉表现和绘制难度。
- 输入：主题、年级、风格、纸张方向、额外主题说明。
- 描绘：从彩色原图提取轮廓，白底浅灰线条，原有图案和文字位置保持一致。线条深浅与粗细分别可调，可下载 PNG 或打印。转换在浏览器本地完成，不额外消耗订阅额度。高分辨率图像的最长边限制为2400像素以兼顾手机内存。
- 任务：真实状态与计时，支持取消和刷新恢复；每次只生成一张，超时15分钟自动终止。画稿保存在 `data/jobs`，服务重启会恢复最后的画稿，未完成的任务标为中断。

## 设置

复制 `.env.example` 为 `.env`，按需调整：

| 参数 | 说明 |
| --- | --- |
| `PORT` | 默认8787，端口不可用时换成其他端口 |
| `HOST` | 默认127.0.0.1，适合frp；需要局域网直连时设0.0.0.0 |
| `CODEX_BIN` | Codex可执行文件或bin/codex.js的完整路径，通常自动寻找即可 |
| `CODEX_MODEL` | 默认 `gpt-6.1-sol`，也可指定当前账号有权限使用的模型；不会自动降级 |
| `CODEX_REASONING_EFFORT` | 默认 `high`，会同时传入会话设置和生成请求 |

本机 Codex 工作进程仅启用图片生成，禁用命令执行、浏览器、连接器和多代理。不会将用户主题插入命令行。

浅灰描绘版支持独立调整线条深浅（10–50%）和粗细（1–5档），默认极细1档。所有档位都以描绘用细线为准：先将轮廓收窄，再以小幅度柔化侧边调整粗细，最粗档也不会大幅扩张文字和图案。拖动滑块会更新预览；下载和打印使用当前预览。转换在浏览器本地完成，不消耗额外生成额度。

已在当前电脑验证：GPT‑6.1 Sol high 使用真实订阅出图成功、彩色图的浅灰轮廓转换、线条粗细1至5档及独立深浅调整、服务重启后的画稿恢复、390像素手机布局（无横向溢出），以及辅助浏览器工具的有效输入和无效输入处理。
